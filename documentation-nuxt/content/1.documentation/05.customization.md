The project supports full customization including styling via CSS variables and asset management.

## Global Styles

Global styles and CSS variables are located in the `src/app/styles` folder. This is where you control the overall look and feel of the application.

![CSS Folder](/images/03.png)

### Edit CSS Variables

You can customize the appearance of the entire application by editing CSS variables in any file within the `src/app/styles` folder. These variables define colors, spacing, fonts, and other design properties, allowing you to easily adapt the theme to your brand or preferences.

For example, in `src/app/styles/_variables.css` you might see:

```css [src/app/styles/_variables.css]
:root {
  --white-color: #fff;
  --main-yellow: #f5c102;
  --main-color: #193364;
  --text-color: #60708e;
  --accent-color: #ff4343;
  --mint-green: #3eb290;
  --border-color: #ced6e1;
  --body-text-color: #4c4c60;
  --background-color: #f2f7fc;
  --placeholder-color: #ced6e1;

  --header-height: 50px;
  --footer-height: 90px;
  --screen-width: 600px;
  --tab-bar-height: 60px;
}
```

## Scoped Styles

In addition to global styles, each screen component has its own local styles defined inside a `<style scoped>` block at the bottom of the `.vue` file. Scoped styles apply only to the current component and do not affect other parts of the application.

```vue [src/pages/Home.vue]
<style scoped>
.container {
  padding: 16px;
  background-color: var(--background-color);
}
</style>
```

::callout{icon="i-lucide-info" color="info"}
Scoped styles are the recommended place for component-specific overrides. Use global CSS variables for shared design tokens and `<style scoped>` for layout or element-level adjustments unique to a screen.
::

## Local Assets

The project uses a minimal set of local assets. Most images are loaded via external URLs for easy customization.

::callout{icon="i-lucide-file-image" color="info"}
The project contains only one local asset file located at `src/assets/01.png`. All other images are loaded via external URLs defined within the Next.js `Image` component.
::

## How to Change Images

::steps

### Replace a Local Image

If you want to replace the local image (`src/assets/01.png`), simply put your new image file in the same location and use the same filename. This will update the image everywhere it is used in the project.

### Replace an Image URL

If the image is loaded via an external URL, find the `Image` component in the source code and swap the existing URL with your own:

```tsx
// Before
<Image src="https://old-image-url.com/photo.jpg" alt="description" />

// After
<Image src="https://your-new-url.com/photo.jpg" alt="description" />
```
